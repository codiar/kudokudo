# Kudo Kudo Cafe

منيو وموقع كودو كودو كافيه، مبني باستخدام React وVite وTailwind CSS.

## النشر على GitHub Pages

1. ارفع محتويات المشروع إلى مستودع GitHub.
2. تأكد أن الفرع الرئيسي اسمه `main`.
3. افتح **Settings → Pages**.
4. اختر **GitHub Actions** كمصدر للنشر.
5. ادفع أي تغيير إلى `main`، وسيقوم GitHub ببناء الموقع ونشره تلقائيًا.

لا يحتاج المشروع إلى خادم أو قاعدة بيانات لتشغيل المنيو والسلة والفاتورة.

## تشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```
